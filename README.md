# CENSUS PE TESTING APP 2027

Offline-ready Population Enumeration testing application.

The app is published as a single static `index.html` and can be opened directly in a browser or served through GitHub Pages.

## Advertising

Adsterra Social Bar (ID 32112101) and Native Banner (ID 32112102) placements are included. Ad content is supplied dynamically by the advertising network; category controls should be configured in the Adsterra account.
